SMARTAGRI SOFTWARE PROTOTYPE

Project:
Object-Oriented Design of an IoT-Based Smart Agriculture Monitoring System

This is a software-only prototype. It simulates:
- Soil moisture sensor
- Temperature sensor
- Humidity sensor
- Water pump/irrigation actuator
- Farm controller
- Monitoring dashboard

How to run:
1. Extract the ZIP.
2. Open index.html in Google Chrome/Edge.
3. Use the simulation buttons.
4. Capture screenshots showing:
   - Dashboard
   - Dry soil -> Pump ON
   - Normal soil -> Pump OFF
   - Random sensor readings
   - Sensor history

Important:
This prototype does NOT claim to use physical IoT hardware. It demonstrates the proposed IoT monitoring and irrigation-control logic using simulated sensor data.
